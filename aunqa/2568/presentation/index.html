ปีที่ 1: ฐานทฤษฎีและการเริ่มต้นงานวิจัย

  • นำเสนอและผ่านการอนุมัติหัวข้อโครงร่างวิทยานิพนธ์ (Thesis Proposal Defended) ที่มีความเป็นไปได้เชิงวิศวกรรม

จริยธรรมของข้อมูลและความโปร่งใส (Affective A5) แสดงออกถึงความซื่อสัตย์สุจริต ปฏิบัติตามจริยธรรมวิจัยและกฎหมายข้อมูลส่วนบุคคล (PDPA) ในการวิเคราะห์ชุดข้อมูลเชิงลึก
*วิชานี้มีความสอดคล้องกับ PLO 1 (100%), PLO 2 (80%), และ PLO 4 (Ethics 100%)

รูบริกการประเมินแบบวิเคราะห์ (Analytic Rubric) สำหรับโครงงานพัฒนาโมเดลปัญญาประดิษฐ์ (CLO 2)

เกณฑ์ประเมิน (Criteria) ดีมาก (5 คะแนน) ดี/พอใช้ (3-4 คะแนน) ปรับปรุง (1-2 คะแนน)
1. การออกแบบสถาปัตยกรรม (Model Design) เลือกและปรับแต่งโครงสร้างโมเดล (เช่น Transformer, LLMs) สอดคล้องกับโจทย์อย่างเหมาะสมและครบถ้วน ใช้งานได้จริงมีประสิทธิภาพสูง เลือกใช้โมเดลตรงกับโจทย์แต่ไม่มีการปรับแต่งหรือดัดแปลงเพิ่มเติม หรือประสิทธิภาพปานกลาง โมเดลไม่ตรงกับลักษณะข้อมูลหรือโจทย์ ส่งผลให้การเรียนรู้ล้มเหลว (Failed to train)
2. การทดสอบและการวัดผล (Evaluation) ทดสอบบน Test Set อย่างถูกต้อง ครอบคลุมหลายมาตรวัด (Accuracy, F1-Score, ROC) และเปรียบเทียบ Baseline ได้สมบูรณ์ วัดประสิทธิภาพโดยใช้มาตรวัดพื้นฐานเท่านั้น ขาดการวิเคราะห์เปรียบเทียบที่รอบด้าน วัดผลด้วยมาตรวัดที่ไม่ถูกต้อง หรือรายงานเฉพาะผลบน Training Set (Overfitting)
3. จรรยาบรรณข้อมูล (Data Privacy/PDPA) อ้างอิงแหล่งที่มาของชุดข้อมูล มีการกำจัดข้อมูลระบุตัวตน (Anonymization) ป้องกันข้อมูลรั่วไหล 100% อ้างอิงแหล่งที่มาของข้อมูลแต่ไม่มีขั้นตอนการรักษาความเป็นส่วนตัวที่รัดกุมเพียงพอ นำข้อมูลที่มีลิขสิทธิ์หรือข้อมูลส่วนบุคคลมาเผยแพร่/ใช้งานโดยไม่ได้รับอนุญาต
