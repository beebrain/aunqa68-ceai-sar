# AUN-QA เอกสารและหลักฐาน

โฟลเดอร์นี้รวมเนื้อหาที่เกี่ยวกับการประเมิน AUN-QA แยกตามปีการศึกษา

## โครงสร้าง

```
aunqa/
  2568/                    ← ปีการศึกษา 2568 (AUN-QA Version 4.0)
    evidence/              ← ไฟล์หลักฐาน PDF/CSV (เดิม Eviden_aunqa68)
    source-docs/           ← เอกสารต้นฉบับ markdown/PDF สำหรับ SAR
    presentation/          ← สไลด์นำเสนอการประเมิน
    criteria/              ← เกณฑ์ SAR แต่ละข้อ (C1–C8)
    guidelines/            ← แนวทางประเมิน
    eviden.html            ← ดัชนีหลักฐานแบบโต้ตอบ
    search-index.json      ← ดัชนีค้นหาหน้า SAR
    …                      ← หน้า SAR อื่น ๆ (program, clo, summaries ฯลฯ)
```

## URL บนเว็บ

| หน้า | URL |
|------|-----|
| หน้าแรกหลักสูตร | `/index.html` |
| หลักฐาน AUNQA 68 | `/aunqa/2568/eviden.html` |
| สไลด์ประเมิน | `/aunqa/2568/presentation/` |
| SAR Reference | `/aunqa/2568/criteria/1.html` |

## ปีถัดไป

เมื่อเริ่มรอบประเมินใหม่ ให้สร้างโฟลเดอร์ `aunqa/25XX/` แล้วคัดลอกโครงสร้างจาก `2568/` เป็นต้นแบบ
