Stakeholder Insights
Stakeholder

เสียงจากผู้มีส่วนได้ส่วนเสีย

ข้อมูลจากการสัมภาษณ์ แบบสอบถาม และความต้องการของตลาดงาน เพื่อปรับหลักสูตรให้สอดคล้องกับการทำงานจริง

สถานประกอบการและตลาดงาน

  • ใช้ Python, R, SQL, SPSS, Excel และ Power BI
  • วิเคราะห์ข้อมูล สร้าง Dashboard และแบบจำลองพยากรณ์
  • ประยุกต์ Machine Learning และ AI กับโจทย์ธุรกิจ
  • สื่อสารผลการวิเคราะห์และทำงานร่วมกับผู้อื่นได้

ศิษย์เก่า

  • เพิ่มสื่อการเรียนรู้ด้านคณิตศาสตร์ให้นักศึกษาเรียนเพิ่มเติม
  • เชื่อมหลักคณิตศาสตร์กับการวิเคราะห์ การวางแผน และข้อมูล
  • เน้นการนำความรู้ไปใช้กับสถานการณ์และการทำงานจริง

นำมาใช้ในการปรับปรุงหลักสูตร

  • เพิ่มรายวิชาด้านการวิเคราะห์ข้อมูล เครื่องมือดิจิทัล AI และ Machine Learning
  • เสริมการพยากรณ์ การสุ่มตัวอย่าง การสร้าง Dashboard และการสื่อสารข้อมูล
  • จัดการเรียนรู้ผ่านข้อมูลจริง ชิ้นงาน โครงงานนวัตกรรมธุรกิจ และ CWIE

เรียนรู้จากโจทย์จริง

  • Problem-Based และ Project-Based Learning
  • ใช้ชุดข้อมูลจริง กรณีศึกษา และโจทย์จากองค์กร

ทักษะวิเคราะห์ข้อมูลครบวงจร

  • คณิตศาสตร์ สถิติ วิทยาการข้อมูล และการพยากรณ์
  • Python, R, SQL, Power BI และ AI
  • จัดการข้อมูล สร้างแบบจำลองและแดชบอร์ด และสื่อสารผล

นักวิเคราะห์และนักพัฒนานวัตกรรมเชิงข้อมูล

  • วิเคราะห์ปัญหาอย่างเป็นระบบและสร้างแบบจำลอง
  • พัฒนาต้นแบบนวัตกรรมธุรกิจจากข้อมูล
  • สื่อสาร ทำงานเป็นทีม และใช้ข้อมูลกับ AI อย่างมีจริยธรรม
