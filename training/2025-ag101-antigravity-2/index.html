🧾 Case 1 — สรุปบิลใบเสร็จจากภาพสแกนจริง

OCR ภาพใบเสร็จจริง 10 ใบ (ชุดข้อมูลสาธารณะ SROIE) ให้ Agent อ่านภาพ → ตาราง CSV → รายงาน HTML

ผลงาน: expense-sheet.csv + expense-report.html
ดาวน์โหลด ZIP ใบงาน คู่มือ PDF

🏦 Case 2 — ผู้ช่วยนักวิเคราะห์สินเชื่อ

ประเมินผู้สมัครสินเชื่อ 3 ราย (ใบสมัคร JSON, Statement CSV, เครดิตบูโร TXT) ตามเกณฑ์ใน loan-policy.md + What-if Analysis

ผลงาน: loan-evaluation-report.md + loan-dashboard.html
ดาวน์โหลด ZIP ใบงาน คู่มือ PDF

🏥 Case 3 — รายงาน Productivity เวรพยาบาล

วิเคราะห์ตารางเวรพยาบาล 8 คน 177 แถว ให้ Agent ตรวจเจอสัญญาณซ่อน (OT เกิน, ลาบ่อย) ตาม KPI ที่กำหนด

ผลงาน: nurse-productivity-summary.csv + report.html
ดาวน์โหลด ZIP ใบงาน คู่มือ PDF

🚀 Case 4 — สร้างแอปลงทะเบียนด้วย Apps Script

สั่ง Agent สร้างระบบลงทะเบียนอบรมที่บันทึกลง Google Sheets จริง + แดชบอร์ดสถิติ (แทร็ก Copy-Paste หรือ CLASP)

ผลงาน: ระบบลงทะเบียนออนไลน์ Deploy ขึ้นเน็ตจริง
ดาวน์โหลด ZIP ใบงาน คู่มือ PDF
